# Novedades fijas · envío completo desde el navegador

El lector HTTP compartido de certificados y novedades fijas rechazaba un JSON válido cuando dos filas tenían los mismos nombres de campo. Anular, corregir y revisar varias novedades requiere precisamente esos campos repetidos en objetos diferentes. Las pruebas anteriores de grupos usaban un objeto ya decodificado y respuestas directas de una simulación: no acreditaban este tramo del envío real. Se conserva esa limitación en el resultado anterior y se corrige antes de ampliar el circuito.

El lector reconoce duplicados dentro de cada objeto, incluyendo nombres equivalentes escapados, y admite los campos iguales de filas distintas. Reutiliza el transporte que ya usaba el catálogo propio: bytes originales, UTF-8 válido, límite completo, longitud declarada, plazo de lectura y recuperación de streams restaurados por Vercel sin consultar su getter decodificado. Los dos endpoints conservan sus códigos seguros de error. Sesión, origen, membresía, permisos, motivos, identidades, versiones, recibos y claves siguen sujetos a sus comprobaciones anteriores.

Las regresiones ejercitan anulación, corrección y revisión con 45 y 500 filas, texto/Buffer/fragmentos, conexión HTTP local, nulos distintos de cero y recuperación de la clave original. El navegador usa ahora el handler real y la fachada parametrizada, con bytes del POST; únicamente las respuestas de SQL son sintéticas. Los recorridos anteriores de filtro/páginas, revisión, revocación, ocultación, conflicto, acuse incierto, aprobación independiente y móvil se mantienen. El modo publicado compara cada recurso servido con la compilación y mantiene todas las API interceptadas para evitar escrituras municipales.

Es una reparación del circuito de fijas ya instalado117/118/119; no necesita instalar SQL ni modificar formularios. Implementación, pruebas, integración, publicación y aceptación se acreditan por separado en el resultado. Falta la aceptación de Noelia con una operación municipal autorizada.

El modelo inicial de anulación mensual quedó privado y sin ejecutar; no se incorpora a esta reparación. Los frentes rechazados y el trabajo paralelo de firmas permanecen excluidos.
