# Noelia · lectura local de certificados escolares

Incremento de ESC-IA-03: Personas → legajo → Grupo familiar → Registrar certificado → «Leer datos del archivo y revisar». Elegir una foto JPEG/PNG o un PDF estático; leer su texto nativo o solicitar la lectura de imagen de la página elegida. Comparar cada propuesta con la página y su cita, marcar los campos revisados y presionar «Usar campos revisados». Guardar certificado continúa como una acción separada del registro existente.

Se reconocen únicamente líneas con etiquetas explícitas de institución, nivel, curso/sala/grado, ciclo lectivo, emisión y vencimiento. No se completan identidades, presentación municipal, importes o motivos desde el documento. No se cambia el hijo elegido, se deduce curso por edad, se corrigen dígitos por intuición ni se inventa un vencimiento anual. La presentación se informa manualmente. Una ausencia, fecha inválida o contradicción requiere completar el campo manualmente; una edición manual posterior impide sobrescribir toda la selección afectada.

El texto nativo reutiliza PDF.js; las imágenes y páginas escaneadas reutilizan el worker OCR español ya instalado, cargado desde el mismo sitio y ejecutado en el dispositivo. No hay proveedor nuevo, transmisión del documento, credencial en el navegador ni almacenamiento de propuestas en localStorage/sessionStorage. El lector mantiene sus límites de tamaño, páginas, píxeles y duración; rechaza PDF protegidos, con acciones, formularios o adjuntos. Si no se puede leer, el formulario manual sigue disponible. La foto original y sus ajustes conservan el circuito privado existente de PDF con original adjunto.

Cada campo propuesto muestra su texto y página, permanece sin seleccionar y necesita revisión humana. La puntuación OCR no autoriza aceptación. Cambiar archivo, vista de foto, familiar o modalidad; retirar permisos; ocultar la página o cerrar la ficha elimina textos, píxeles y selecciones y cancela respuestas tardías. Los campos manuales se conservan. Durante un envío incierto no se puede abrir el lector ni cambiar el cuerpo o la clave del intento existente.

Este cierre proporciona ayuda local de transcripción para el administrativo autorizado. No guarda un historial de extracción/correcciones ni confirma autenticidad, escolaridad o haberes. La fase completa conserva pendientes: reconocimiento y contraste documental de identidad, formatos narrativos y manuscritos, medición de precisión con casos municipales autorizados, auditoría durable de propuestas y revisiones, capacidad del archivo para uso masivo y autoservicio con autorización propia. No se presenta OCR como un proveedor generativo ni los ensayos sintéticos como aceptación de Noelia.
