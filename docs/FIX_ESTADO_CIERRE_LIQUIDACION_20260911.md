# Estado de cierre: no convertir ausencia de evidencia en preliquidación

Se comprobó una inconsistencia entre la biblioteca de documentos y el lector anterior: un source_closed_flag nulo se presentaba como abierto en el detalle. 052 cambia únicamente esa expresión en la función autorizada. 1 corresponde a cierre informado; 0, abierta/preliquidación; otro valor o nulo, estado de cierre no informado.

La interfaz, PDF y Excel comparten la misma denominación. Los datos originales, importes, cálculos, controles de acceso y firma no se modifican. Un control aritmético coincidente no certifica cierre ni pago.

Orden de publicación: frontend compatible con unknown, comprobación de assets productivos, aplicar la expresión SQL revisada y verificar procedencia/grants. Función y archivos anteriores conservados en historial. La migración se detiene ante un cuerpo inesperado, en lugar de reemplazar código no revisado.
